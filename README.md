# Hamed Al-Alim Family Tree Android App

Arabic-first offline Android app for exploring the Hamed Al-Alim family tree.

## Build an installable APK

1. Upload the original project archive to the repository root with this exact filename:
   `Hamed_AlAlim_Family_Android_Project.zip`
2. GitHub Actions automatically extracts the project and builds both debug and release APKs.
3. Open the **Actions** tab and select the latest **Build Hamed Al-Alim Family Tree APK** run.
4. Download the artifact named **Hamed-AlAlim-Family-Tree-APK**. The release APK is `Hamed-AlAlim-Family-Tree.apk`.

The release APK is signed with the standard debug key so it can be installed directly for testing. It is not a Play Store production signing key.
